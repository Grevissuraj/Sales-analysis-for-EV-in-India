# 🔋 EV Sales in India – Power BI Dashboard

## 📊 Dashboard Overview  
This Power BI dashboard provides an in-depth analysis of **Electric Vehicle (EV) sales in India** from **2014 to 2024**, offering valuable insights into regional trends, vehicle categories, market performance, and employment impacts.

The dashboard is designed for policymakers, market analysts, and EV enthusiasts looking to explore the rapid growth and adoption of electric vehicles in India.

## 🧩 Problem Statement  
India's EV market is growing rapidly, but stakeholders often lack a centralized, interactive platform to analyze national sales data across different vehicle types, states, and years. There was a need for a visual tool to:

- Track EV adoption trends  
- Identify top-performing regions and vehicle segments  
- Assess employment contribution by EV segment  
- Support data-driven policy and business decisions  

---

## 🎯 Purpose  
This project aims to create a **comprehensive and interactive Power BI dashboard** that:

- Monitors national EV sales by year and month  
- Highlights top-selling states and EV categories  
- Shows sales distribution across vehicle types  
- Analyzes job generation by company size and vehicle segment  
- Enables filtering by year, vehicle category, and type for focused analysis  

---

## 📌 Key Metrics & Visuals  
- **Total EV Sales** (2014–2024)  
- **Top States by Sales** (e.g., Uttar Pradesh, Maharashtra)  
- **Top-Selling Vehicle Types** (e.g., M-Cycle/Scooters, E-Rickshaws)  
- **Monthly Sales Trends**  
- **EV Sales by Category** (2-Wheelers, 3-Wheelers, etc.)  
- **Sales Distribution by Year**  
- **Jobs Created by Company Size & EV Type**  
- **Interactive Filters**: Year, Vehicle Category, State, Type  
- **Geographical Map**: EV sales concentration across Indian states  

---

## 🌟 Features  
- Clean, modern UI with dark theme for better visual clarity  
- Multi-page interactive layout with KPI cards, donut charts, line and bar charts  
- Slicer filters for custom analysis (years, vehicle types, states)  
- Hover-enabled insights and dynamic visuals  
- Integrated Bing Map for geographic distribution

## 🚀 How to Use  
1. Download the `.pbix` file from the GitHub repo  
2. Open it in Power BI Desktop  
3. Use slicers (year, state, vehicle type) to interact with the dashboard  
4. Explore visual elements to identify insights across various metrics
